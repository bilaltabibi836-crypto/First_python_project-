# 🎸 Band Name Generator

**Day 1 of my 100 Days of Python Challenge** 🚀

## About
A simple Python program that creates a band name for you. It asks for the city you grew up in and the name of a pet, then combines them.

## How it works
1. Enter the city you grew up in
2. Enter the name of a pet
3. Get your band name!

## Example
```
Welcome to the Band Name Generator!
Which city did you grow up in?
paris
What is the name of a pet?
max
Your band name could be: Paris Max
```

## How to run
```
python main.py
```
